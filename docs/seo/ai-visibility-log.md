# AI visibility log

A weekly 15-minute check of whether AI answer engines mention or cite DealDock for the questions our buyers ask. Paid trackers (Otterly, Peec, Ahrefs Brand Radar) automate the same check; they aren't worth paying for until there's something to track.

## How to run it

1. Use a logged-out or private window. Run each prompt in **ChatGPT** (search on), **Perplexity**, **Google** (AI Overview or AI Mode), **Gemini**, **Claude** (web search on) and **Copilot**.
2. For each answer, record whether DealDock is named, whether a dealdock.io page is cited (and which), and which other tools or sites are named.
3. Add one row per engine and prompt to the table below, newest first. Note anything surprising (wrong facts about DealDock, a mix-up with the other DealDocks) under "Notes".
4. Also check Search Console (Performance; Generative AI report), Bing Webmaster Tools (AI Performance) and the GA4 "AI" channel. Write one line of totals per week.
