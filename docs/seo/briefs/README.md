# Briefs

One file per article or tool, `<slug>.md`, written by the `blog-research` skill from `.claude/skills/blog-research/brief-template.md`. Writers (`blog-write`) and fact-checkers (`blog-verify`) read the brief's source dossier first. Keep briefs after publishing: they're the starting point for refreshes.

The November 2026 batch predates this folder. Its assignments are kept as examples in `.claude/skills/blog-write/assignment-template.md`, and each live article's own links are its source list.
